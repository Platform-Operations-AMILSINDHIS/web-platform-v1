### 🔐 Accessing the Admin Panel
1.  Navigate to: `https://amilsindhis.org/admin/auth`
2.  Log in with your administrator credentials.
3.  **Security Note**: Never share admin passwords via plain text (WhatsApp/Email). Use a secure manager.

---

### 1. Dashboard Overview
The Admin Dashboard is your central hub for managing the community.

*   **Memberships Tab**: View applications for KAP and YAC.
*   **Matrimony Tab**: View applications for the Matrimony portal.
*   **Search & Filters**: Use the toolbar to filter by status (Pending/Approved), applicant name, or membership type.
*   **Real-time Updates**: The dashboard updates automatically when new forms are submitted.

---

### 2. Reviewing Applications
Each row in the tables represents a submission.

1.  **View Details**: Click the **"View"** button to see the full form submission and user profile.
2.  **Verify Payment**: Check the Payment ID against bank records for new members.
3.  **Approval**:
    *   Click **"Approve"**.
    *   The system will automatically generate a unique Membership ID.
    *   The user will receive a professional PDF membership card via email.
4.  **Rejection**: If details are incorrect or eligibility is not met, click **"Reject"**. The user will be notified.
5.  **Deletion**: Use the 🗑️ icon to remove duplicate or test entries. *Warning: This only deletes the submission record, not the user account.*

---

### 3. Matrimony Profile Requests
When a user "Requests a Profile" for a match:

1.  Click the **"Profile Requests"** button (top right) to see pending requests.
2.  **Accept**: Clicking accept will automatically generate a full matrimony PDF of the requested person and email it to the requester.
3.  **Record Keeping**: The office email (`amilsindhis@gmail.com`) is automatically CC'd on all approved requests.

---

### 4. CMS Guide: Managing Content (Sanity)
Content like Events, Blog Posts, and General Info is managed via the **Sanity CMS**.

#### **Accessing the CMS**
*   **URL**: `https://amilsindhis.org/studio` (or your specific Sanity project URL).
*   Log in with your Sanity account.

#### **Managing Events**
1.  Select **"Events"** from the sidebar.
2.  **Create New**: Click the plus (+) icon.
3.  **Fields**:
    *   **Title & Slug**: The name of the event.
    *   **Date**: Set the event date and time.
    *   **Display Picture**: Upload a high-resolution image.
    *   **Description**: Use the rich text editor for event details.
4.  **Publish**: Click the green **"Publish"** button to make it live on the site.

#### **Managing Blog/Catalog**
1.  Select **"Blog"** or **"Catalog"**.
2.  Update text, images, or tags.
3.  **Drafts**: Changes are saved as drafts until you click **"Publish"**.

---

### 5. Admin Management
To add a new administrator:
1.  Click **"Add Admin"** in the top header.
2.  Provide an email and username.
3.  The new admin will receive their login link and temporary password via email.
